Three rules

What carries it.

A second way to run features with Agent Farm, next to greenfield.

1
One front door.You talk only to bigbrain/orchestrator. Questions, approvals and pages to look at all reach you through it.
2
The plan is the program.Every approved cover sheet ships a control-flow.json: what to build, which flows to prove, where review happens.
3
Reviews are planned or asked for.A reviewer runs only at a review step in the control flow, or after you say yes. Implementers never start reviewers.

The front door

Workers never ask you directly.

They write a status file and report. The orchestrator relays the question and sends your answer back.

YouOrchestratorWorkers

States: running · needs_you · checkpoint · blocked · done · failed. The full contract is instructions/contract.md.

One feature

From idea to merge.

The planner plans, you approve, the implementer runs the control flow step by step.

You actOrchestrator runs itRuns on its ownOnly when planned or needed

At a review step the implementer pushes and waits; the orchestrator starts exactly one reviewer for that scope; must-fix items go back, a follow-up checks only those, then continue:. Checkpoints need a reason_kind: irreversible, schema, security or shared-contract. Details: control-flow.md.

The five helpers

verifierDrives the app: QA, mockup fidelity, jank.
explorerOne read-only codebase question, or a cold read.
researcherOne web question.
review-workerA finder or a checker for the reviewer.
socratesOne challenge before you pick an option.

Claude helpers under a Claude profile run natively; a helper on the other vendor runs as a separate process.

Documents

Pages you can check.

Every page comes from a template, carries a doc-meta block and stable IDs, and passes check-bundle before it changes stage.

IDs

PrefixWhatDefined in
SC-nsuccess criterionbrief (index.html)
P-n, J-n, S-npackage, journey (Given/When/Then/Check), suite (command → result)cover sheet
D-n, Q-ndecision, and the relay question it came fromdecisions.html
F-nreview findingfindings/*.md

IDs are never reused; documents cite them instead of copying text.

Two markers

Blocks approval
[NEEDS DECISION: …]
Becomes a question to you before the page can change stage.
Made without asking
[ASSUMPTION: …]
Marks a choice made without asking.

What check-bundle checks

  • required sections, doc-meta, ID definitions and citations
  • both JSON sources against their schemas
  • the cover sheet still shows what control-flow.json will run
  • nobody added, removed or reworded a verification check
  • every J/S has a verdict before done
  • relative links resolve

Quick fixes

Only on your word.

Ask for a simple fix, or approve one in words, and it goes straight to an implementer.

Get started.

agent-farm plugin install bigbrain
agent-farm run bigbrain/orchestrator --directory /path/to/project

Run it as a Pane Session coordinator or in a Pane tab. Pane must be installed with runpane on PATH.
