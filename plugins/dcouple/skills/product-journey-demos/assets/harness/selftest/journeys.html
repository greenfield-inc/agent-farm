Notebook user journeys

1. Write and save a note

Everyone seen in code

Goal: save a note for later.

  1. Start on the Notes page.
  2. Type the note in the "Write a note" box.
  3. Click Save note.
  4. The note shows at the top of the list.

Where it goes wrong: an empty note is saved as a blank row.

Gap: notes can't be edited after saving.

Evidence: app.html, the Save note handler.
