# Reconciliation page template

A self-contained HTML page, saved as `reconciliation.html` in the bundle.

```
Reconciliation: {swarm topic}                      {N agents · date}
Bottom line        3 to 5 bullets: what holds, what changed, what needs a decision
Coverage           drawing: territory chunk → agent → status (complete | thin | failed)

Security / urgent  call-out, shown first, when any finding is a security or data risk

Conflicts          topic | what we assumed or decided | what the evidence says |
                   how it was resolved | status (resolved | needs decision | verify)

Verified           claims you or a follow-up agent checked against the source
Reported only      claims you used but didn't verify, each with its agent's evidence link
Gaps               chunks that came back thin, and unanswered questions, each with its
                   next step
Decisions needed   numbered, each phrased as an interview question with your
                   recommendation
Evidence           one link per agent's saved findings
```
