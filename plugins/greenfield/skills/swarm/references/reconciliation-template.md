# Reconciliation page template

A self-contained HTML page, saved as `reconciliation.html` in the bundle.

```
Reconciliation: {topic}                         {N agents · date}
Bottom line       3 to 5 bullets: what holds, what changed, what needs a decision
Coverage          drawing: chunk → agent → complete | thin | failed
Urgent            call-out first, for any security or data risk
Conflicts         topic | assumed or decided | evidence says | resolution |
                  resolved | needs decision | verify
Verified          claims checked against the source
Reported          claims used as reported, each with its evidence link
Gaps              thin chunks and open questions, each with its next step
Decisions needed  numbered, phrased as interview questions with a recommendation
Evidence          one link per agent
```
