# Worked examples

Every worked example shipped with the SEO skills, what it shows, and the original it distils. Paths are relative to the plugin's `skills/` folder. A role can open only the files its own skills bundle; the "Bundled for" column says which roles have each one. Originals are cited by title and date; they are not shipped.

Product A is an open-source developer tool for running coding agents in parallel (real numbers). Product B is a B2B healthcare SaaS with a free plan (ratios only).
