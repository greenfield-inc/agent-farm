# Addendum template

A decision that lands while workers are running goes out once, as a file, to every worker it affects. Number addenda per Session and never edit one after sending; correct it with the next.

```
Plan addendum {N} ({date}): {topic in a few words}
Affects       {work items or lanes}; others ignore this
Decisions     - {decision, in one sentence, with the reason when it isn't obvious}
              - {a reversal names what it replaces: "replaces addendum 2, item 3"}
Do            Revise your plan or work to match, then report again as usual
              (or "No reply needed")
Source        decision log Round {M}
```

Deliver it with the host's file-pointer submit to each affected worker, and confirm delivery (taken or queued) for every one. Add it to the workstream map's Addenda table.
