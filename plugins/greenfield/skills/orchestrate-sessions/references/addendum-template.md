# Addendum template

A decision that lands while workers run goes out once, as a numbered file, to every worker it affects. Correct an addendum with the next number.

```
Plan addendum {N} ({date}): {topic}
Affects       {work items or lanes}; others skip it
Decisions     - {decision in one sentence, with its reason}
              - {a reversal names what it replaces: "replaces addendum 2, item 3"}
Do            revise your plan or work to match, then report again
Source        decision log Round {M}
```

Deliver it with the host's file-pointer submit, confirm each delivery (taken or queued), and add it to the workstream map's Addenda table.
