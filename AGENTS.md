# Agent Farm

Native Claude/Codex CLI launcher. Node 22.15+, pnpm 11, TypeScript. This repository is public.

## Commands

- `pnpm install --frozen-lockfile`, then `pnpm typecheck` and `pnpm test` (`test` builds first). Run both before committing runtime changes.
- Run the CLI from source with `node dist/cli.js help`.
- Keep tests and manual checks off the real user config: see [docs/development.md](docs/development.md#keep-tests-off-your-real-config).

## Rules

- Never let checks touch the real user config or state. CLI commands default to `~/.config/agent-farm` and ignore `AGENT_FARM_CONFIG_ROOT`, so pass `--config-root <temp dir>`. Launches, `workspace trust`, the bare menu, `init`, and `doctor` also write under `~/.local/state` or `~/.cache`, so set `HOME` to a temp dir as well.
- `plugins/dcouple/` is published here by maintainers from a separate repository, and `plugins/orchestra/` is generated by `scripts/vendor-orchestra.mjs`. Never edit either by hand. See [RUNBOOK.md](RUNBOOK.md).
- During an active experiment, profiles are append-only: never delete, rename or edit one; create a -vN profile instead. If you are unsure whether an experiment is running, ask the maintainer before changing a profile.
- `src/runtime.ts` is copied into every launch bundle as `runtime.mjs`. Import only `node:` builtins there.
- Never put credentials, personal paths, or local workspace connections in a plugin or a doc.
- Use HTTPS for git. Do not commit tmp/, dist/, node_modules/, .agent-farm/generated/, or .DS_Store.
- README illustrations must follow the pixel-farm theme in `docs/assets/visual-style.md`, using `docs/assets/agent-farm-banner.png` as the visual reference.
- Update or delete the doc: a change that alters a command, flag, config key, env var, path, default, or release step must update every doc that states it in the same PR. Delete doc text you find stale rather than leaving it. Each topic has one home (see below); link to it instead of restating it.
